开始游戏

和朋友一起联机

客户端自带联机能力：局域网分享码（点对点）+ WebSocket 服务器，两种方式都能用（客户端为英文原版界面，教程里已对照标注）

  1. 房主开放局域网

    进入世界后按 Esc →「对局域网开放」（Open to LAN）→ 选择中继服务器 → 客户端生成一串分享码，复制发给好友。

  2. 好友输入分享码

    好友打开同一版本客户端 → 多人游戏（Multiplayer）→「加入局域网世界」（Join LAN World）→ 粘贴分享码，几秒后进入同一个世界。

  3. 建立点对点连接

    客户端通过中继服务器交换连接信息后转为 WebRTC 点对点传输；房主退出则世界关闭。

关于「中继服务器」

中继只负责牵线（信令），游戏数据是两端直接传输的。本站已在客户端里预置 4 个中继，默认优先国内公益节点 wss://relay.mcjs.link（由 MCJS 提供，请勿滥用）；连不上时，在游戏内的联机界面切换到列表里的其它中继即可。

连不上怎么办？

① 优先换中继服务器再试；② 校园网 / 部分公司网络会限制 WebRTC 的 UDP 流量，换个网络或开手机热点最有效；③ 确认双方用的是同一版本客户端；④ 也可以直接玩服务器：多人游戏 →「添加服务器」填 wss:// 地址（本站为 HTTPS 页面，ws:// 会被浏览器按混合内容拦截）。

常见问题

这是官方《我的世界》吗？

Eaglercraft 是社区开源项目：把 Java 版《我的世界》客户端编译成浏览器能运行的形式，并复刻了原版的玩法与界面。它不是 Mojang / 微软的官方产品，本站与 Mojang、微软没有任何关联，仅供学习交流，请支持正版游戏。

JavaScript 版和 WASM 版有什么区别？

两者玩法完全一样。JavaScript 版兼容所有浏览器但文件更大；WASM-GC 版用 WebAssembly 重新编译，加载更快、运行更流畅，但需要较新的 Chrome / Edge（119+）。拿不准就用 JavaScript 版。

界面是英文的？

本站用的是 Eaglercraft 官方原版构建，界面为英文（官方版不带中文语言包）。本页教程已把联机相关的关键按钮对照标注；合成、物品等术语与中文版一一对应，基本不影响游玩。

打开后黑屏或一直在加载？

首先确认用最新版 Chrome / Edge；客户端文件有 16–83 MB，第一次加载需要等几秒到十几秒，加载完成后浏览器会缓存。如果中途切换过标签页，回来时可能看到「按任意键 / 点击继续」（Press any key / Click to focus）提示，点一下页面即可继续。1.12.2 版本第一次打开如出现语言列表，点选 English 即可。WASM 版如果打不开，说明浏览器版本太旧，改用 JavaScript 版即可。

联机连不上怎么办？

见「联机教程」里的说明：优先更换中继服务器；避开对 UDP 限制严格的网络（校园网、部分公司网络）；确认双方版本一致。1.5.2 版本的「共享世界」也可以同一台电脑开两个浏览器（普通 + 隐身窗口）自测联机流程。

存档会丢吗？怎么备份？

世界保存在浏览器本地，清理浏览器数据会一并删除。重要世界请在客户端里导出保存（EaglercraftX：主菜单 → 备份 / 导出世界），换设备时再导入。

手机上能玩吗？

能打开，但《我的世界》本来是为键盘鼠标设计的，触屏操作体验有限。建议在电脑上玩；平板上可以简单建造和探索。
